3 · รูปนาฬิกา

อัปโหลดรูปสำหรับรหัสนี้ ลากรูปมาวางหรือคลิกเพื่อเลือก · รูปจะถูกบันทึกเข้าคลังด้วยรหัสในช่อง Reference
600 × 814 px · ส่งออกละเอียด 4 เท่า (2400 × 3256)

คลังรูปนาฬิกา · Watch images

รูปที่มีอยู่ในคลัง ระบบจับคู่กับรหัสนาฬิกา (Reference) ให้อัตโนมัติ

✓ เชื่อมต่อ GitHub แล้ว · ลากรูปมาวาง ใส่รหัส/รุ่น แล้วกด บันทึก รูปจะเข้าคลังทันที
บันทึกรูปเข้าคลังได้ในคลิกเดียว: เชื่อมต่อ GitHub (ทำครั้งเดียวต่อเครื่อง)
  1. เปิด หน้าสร้าง token ↗ (ล็อกอินบัญชี nggtimepieces) · Token name: enquiry-letters · Expiration: เลือกนานสุดที่ต้องการ
  2. Repository access: Only select repositories → เลือก enquiry-letters · Permissions → Repository permissions → Contents: Read and write → Generate token
  3. คัดลอก token มาวางช่องนี้ แล้วกด เชื่อมต่อ

token เก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น · เครื่องที่ไม่ได้เชื่อมต่อยังใช้รูปในคลังได้ตามปกติ

เพิ่มรูปเข้าคลังแบบไม่เชื่อมต่อ (2 ขั้นตอน)
  1. ลากรูปมาวางในกรอบด้านล่าง ใส่รหัสและรุ่น แล้วกด เตรียมไฟล์ ระบบจะตัดขอบ ตั้งชื่อไฟล์ให้ถูก และดาวน์โหลดให้
  2. อัปโหลดไฟล์นั้นเข้าโฟลเดอร์ watches บน GitHub เปิดหน้าอัปโหลด ↗ แล้วกด Commit changes · รอประมาณ 1 นาที แล้วรีโหลดหน้านี้
ลากรูปนาฬิกามาวาง หรือคลิกเพื่อเลือก (เลือกได้หลายรูป) รองรับ PNG, JPG, WEBP, AVIF · ถ้าชื่อไฟล์เป็นรหัสอยู่แล้ว ระบบจะอ่านรหัสให้
